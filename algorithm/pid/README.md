# PID

实现：`nexarm_pid/controller.py`，ROS 包：`nexarm_pid`。

采用位置参考前馈和 PID 反馈。每步误差 `e = r[k] - y[k-1]`，命令为：

```
u_raw = r[k] + Kp*e + Ki*integral(e) + Kd*filtered_derivative(e)
```

默认 Kp=0.6、Ki=0.5、Kd=0.01，采样周期 1/30 秒。微分项使用一阶滤波（旧值权重 0.8）。命令按关节角度和速度限幅；如果积分会加重限幅，则冻结该关节此次积分，避免积分饱和。重新运行清除积分和微分历史。

这些是通用初始参数，并非对每个关节和所有响应时间都最优。它根据实际测量反馈补偿，未使用未来扰动或电机内部真实状态。启动、面板操作及公平比较见 [算法说明](../README.md)。
